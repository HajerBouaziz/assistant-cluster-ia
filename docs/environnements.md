# Environnements logiciels

## Créer un environnement Python
Créez un environnement virtuel avec `python -m venv venv`, activez-le puis installez vos dépendances avec `pip install -r requirements.txt`.

## Utiliser un conteneur
Les images Docker validées sont disponibles dans le registre interne. Un conteneur garantit que le même environnement est utilisé sur le poste et sur le cluster.
